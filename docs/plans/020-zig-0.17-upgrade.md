## What changes for us

### Must change (won't compile)

- **Array multiplication `**` is removed**; `@splat` replaces it
  (`var vec_data: [3]f32 = @splat(0.0);`). 13 uses:
  - `src/core/animator.zig:343`
  - `src/core/lights.zig:50`, `:63`
  - `src/core/gltf/parser.zig:268-271`, `:289`, `:304`, `:319`, `:872`, `:935`
  - `examples/bullets/objects/lights.zig:16`
- **`std.fmt.allocPrint` moved to the allocator**: `allocator.print(fmt, args)`.
  `src/core/animator.zig:1101`, `src/core/shapes/obj_loader.zig:205`.
- **`build.zig`**:
  - `b.args` with `run_exe.addArgs(args)` (around line 121) becomes
    `run_exe.addPassthruArgs()`.
  - `b.lazyDependency` (line 158, `wgpuNativeDependency`) returns
    `error.LazyDependencyNeeded` instead of null (`dependencyLazy`, use `try`); the
    caller's null handling changes to error handling.
  - `std.builtin.OptimizeMode` (lines 167, 192) becomes `std.lang.Optimize` (tags
    lowercase: `debug`, `safe`, `fast`, `small`).
  - `b.addTranslateC` (`wgpuModule`, translating `src/core/wgpu/webgpu.h`) is deprecated
    for the ZSF translate-c package
    (`zig fetch --save git+https://codeberg.org/ziglang/translate-c`, its `Translator`).
    Find out whether the build step still exists in 0.17; if not, this is required.
- **`build.zig.zon`**: `minimum_zig_version = "0.17.0"`; new dependency pins.

### Deprecated (still compiles; do it in the same pass)

- **`@intFromEnum` / `@enumFromInt` become `@backingInt` / `@fromBackingInt`.** 93
  uses (most in `spacesuit.zig`, `toon_soldier.zig`, `turret.zig`, `mesh.zig`,
  `animation_fsm.zig`, `input.zig`). The notes say `zig fmt` migrates them; one `zig fmt`
  pass over our own files (never dependency code), then review the diff.
- `std.builtin` → `std.lang` (only `build.zig` uses it).

### Checked, no change expected

- `@bitCast`: casts with `extern struct` / `extern union` are no longer allowed; ours
  are u32↔f32, u8↔i8 (`mesh.zig`), and `RenderState`, a `packed struct(u4)`, to and
  from `u4` (`pipeline.zig`), all still allowed.
- `@hasDecl` sees only `pub` declarations: the bullets `Scene` uses
  `std.meta.hasMethod` for `update`, `draw`, `drawGui`, `cleanUp`, all `pub`.
- `std.meta.eql`, `stringToEnum`, `fields`: not in the deprecation list.
- Not used here: `@cImport` (removed), `errdefer |err|`, `void{}`, `i0`,
  `StackFallbackAllocator`, `DebugAllocator`, `getLast` / `getLastOrNull`, the bit sets,
  `std.zon`, packed int read / write.
- `main(init: std.process.Init)`, `init.io`, `init.gpa`, `std.Io`, ArrayList: no
  changes we use are in the notes.

### Toolchain

- 0.17 ships LLVM / Clang 22.1.8 and macOS 27.0 headers. The `float.h` patch for
  `__need_infinity_nan` (CLAUDE.md, macOS toolchain note) should no longer be needed:
  build libc++ (zgui, imgui) on an unpatched 0.17; if it works, delete the note.
